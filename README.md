# 📰 Fake News Detection Using Machine Learning

Fake news has become one of the most critical challenges in the digital age, spreading misinformation rapidly through social media and online platforms. This project presents a **Machine Learning–based Fake News Detection System** that classifies news articles as **Real** or **Fake** using **Natural Language Processing (NLP)** techniques and a **Logistic Regression** classifier. The system is integrated with a **Flask web application** to provide an interactive and user-friendly interface.

---

## 📖 Project Overview

The Fake News Detection System analyzes the textual content of news articles and determines their authenticity. The model is trained on a large real-world dataset consisting of thousands of labeled news articles. By applying NLP preprocessing and TF-IDF feature extraction, the system converts unstructured text into numerical representations that can be effectively processed by machine learning algorithms.

This project demonstrates the practical application of **machine learning, text classification, and web development**, making it suitable for **academic projects, final-year submissions, and portfolio demonstrations**.

---

## 🎯 Objectives

- To design an automated system for detecting fake news articles  
- To apply Natural Language Processing techniques for text cleaning  
- To implement TF-IDF for feature extraction  
- To train a reliable machine learning classifier  
- To deploy the trained model using a Flask-based web interface  

---

## ✨ Key Features

- Classifies news articles as **Real** or **Fake**
- Uses NLP-based text preprocessing:
  - Lowercasing
  - Punctuation and number removal
  - Stopword removal
- TF-IDF vectorization for feature extraction
- Logistic Regression classifier for text classification
- High classification accuracy (~99%)
- User-friendly Flask web application
- Lightweight system with no database dependency
